# 合同审查助手（contract review）

一个**在你自己电脑/服务器本地运行**的合同审查小工具。它把三件事结合起来：

1. **规则体检** —— 用一套常见合同风险规则，逐条扫描你粘贴的合同，找出违约金过高、定金/订金混用、霸王条款、单方解除、自动续约、高利贷、连带担保、模糊表述、必备条款缺失等问题。
2. **真实法条核对** —— 联网调用官方、免费、权威的 **国家法律法规数据库**（`flk.npc.gov.cn`），确认相关法律现行有效并给出官方链接，让意见**有据可依**，而不是 AI 凭空生成。
3. **可选的 AI 解读** —— 如果你有 Anthropic API key，工具会把**已检索到的真实法条**作为材料喂给 Claude，做通俗解读（检索增强生成 RAG），避免模型编造条号。

> ⚠️ **重要：本工具是「辅助参考」，不构成法律意见，也不替代执业律师。** 涉及金额较大、担保、股权、知识产权、诉讼等重大事项，请务必咨询律师，或拨打**全国法律援助热线 12348（免费）**。它能帮你「看懂、发现问题、问对问题」，但不能替你做最终法律判断。

---

## 为什么要本地运行？

真正权威的法条数据源是官方的国家法律法规数据库。很多受限网络（包括一些云环境）会拦截该域名，导致无法联网核对。**在你自己的电脑上运行**，就能正常访问官方库、拿到真实法条与官方链接。

## 它做不到什么（请知悉）

- ❌ **接不进付费案例/意见库**（北大法宝、威科先行、法信、裁判文书网等）。它们需要付费订阅且大多无开放 API。本工具预留了 `src/adapters/paidLibrary.stub.js` 模板，**将来你拿到付费库凭证时**可自行接入。
- ❌ 不能保证覆盖所有风险。「没报问题」不等于「没有风险」。

## 快速开始

需要 Node.js 18+（已用 Node 22 验证）。**无需安装任何依赖。**

```bash
cd legal-advisor
node server.js
# 打开浏览器访问 http://localhost:8787
```

把合同粘进左边，点「开始审查」即可。点「载入示例」可看一份故意写满坑的示例合同效果。

### 可选：开启 AI 解读

```bash
export ANTHROPIC_API_KEY=你的key        # Windows PowerShell: $env:ANTHROPIC_API_KEY="..."
export CLAUDE_MODEL=claude-sonnet-4-6    # 可选，默认即此模型
node server.js
```

然后在页面勾选「启用 AI 解读」。AI 会基于检索到的真实法条作答。

### 其它环境变量

| 变量 | 作用 |
|---|---|
| `PORT` | 端口，默认 8787 |
| `DISABLE_BACKEND=1` | 关闭联网核对官方法规库，仅用本地精选法条 |
| `ANTHROPIC_API_KEY` | 设置后启用 AI 解读（可选） |
| `CLAUDE_MODEL` | 覆盖默认模型 |

## 自测官方法规库连通性

```bash
node src/adapters/nationalLawDb.js 合同 违约金
```

能列出几条法规标题+官方链接，说明联网核对正常。若失败，多半是网络拦截了 `flk.npc.gov.cn`（换网络/在本机运行），或官网改版（见下）。

## 目录结构

```
legal-advisor/
├─ server.js                     零依赖本地服务器（静态页 + API）
├─ public/                       前端页面（暗色终端风）
│   ├─ index.html
│   └─ app.js
└─ src/
    ├─ adapters/                 法律后端「插槽」
    │   ├─ registry.js           适配器注册表，统一 search() 接口
    │   ├─ nationalLawDb.js      官方免费法规库适配器（真实数据源）
    │   └─ paidLibrary.stub.js   付费库适配器模板（预留插槽，默认不启用）
    ├─ review/
    │   ├─ segment.js            合同分条
    │   ├─ rules.js              风险规则库
    │   ├─ statutes.js           本地精选《民法典》合同核心条文
    │   └─ engine.js             审查引擎（分条→跑规则→关联法条→联网核对）
    └─ ai/
        └─ claude.js             可选 AI 解读（基于真实法条做 RAG）
```

## 接入付费法律库（将来）

1. 复制 `src/adapters/paidLibrary.stub.js` 为如 `pkulaw.js`；
2. 按厂商官方 API 文档实现 `search()`；
3. 在 `src/adapters/registry.js` 里 `register()` 它。

审查时会自动把它返回的真实案例/意见库结果一并纳入。
**密钥请用环境变量 `PAID_LEGAL_API_KEY` 注入，切勿硬编码或提交到仓库。**

## 关于官方 API 的稳健性

官方库接口为非公开 API，参数/返回结构可能随官网改版变化。适配器对返回结构做了容错解析；一旦联网核对失败，工具会**自动降级**到本地精选法条库并明确标注，不会中断审查。若官网改版导致长期失败，调整 `src/adapters/nationalLawDb.js` 中的请求参数即可。
